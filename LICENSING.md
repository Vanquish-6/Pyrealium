## Source offer

The public project source is https://github.com/Vanquish-6/Pyrealium.
The server identifies its source in startup output and the initialized in-game
chat; players can also use `@source` or `@license`. Builds from Git link to their
commit. Set the build environment variable `PYREALIUM_SOURCE_URL` to a public
HTTP(S) location when distributing or operating a modified version elsewhere.
The `license` / `--license` command prints the complete license.
Distributors and modified-server operators must make sure their offer
points to the complete source for their actual version. A link to an unchanged
upstream repository is not sufficient for private modifications.
